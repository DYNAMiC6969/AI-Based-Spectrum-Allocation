# AI-Based Spectrum Allocation Using Q-Learning

## Project Overview

This project implements an AI-based spectrum allocation system using Reinforcement Learning (Q-learning) in MATLAB.

The objective is to study spectrum allocation in a cellular network and evaluate system performance under different allocation policies and network conditions.

## Objectives

- Implement Q-learning for spectrum allocation.
- Evaluate the performance of the learned allocation policy.
- Compare Q-learning with baseline allocation policies.
- Analyze throughput, QoS violations, and other performance metrics.

## Technologies Used

- MATLAB
- Reinforcement Learning
- Q-learning
- Wireless Communication Systems

## Project Structure

- `MATLAB/` — MATLAB scripts and supporting functions.
- `Results/Plots/` — Generated performance plots.
- `Results/Data/` — Numerical experiment results.
- `Report/` — Project report.

## How to Run

1. Install MATLAB.
2. Open the `MATLAB` folder in MATLAB.
3. Add the folder and its subfolders to the MATLAB path.
4. Run the appropriate main script to execute the experiment.
